# Native UI provenance

`interactive_sam2_gui_ytvis.py` and `utils.py` were adapted from the local
`hograph` project's interactive SAM2 annotation UI so this repository can run
without an external `/home/development/hograph` checkout.

Project-specific startup and lineage persistence live in
`../desktop_annotator.py`. The bundled SAM2 realtime source is separately
licensed under Apache-2.0; see `../vendor/sam2_realtime/LICENSE`.
